近期复盘发现，入口返工和让模型长时间守候普通程序都消耗了资源。更值得保留的是以真实资料核对行情、模拟计算和费用，以及明确登记跑输对照的策略。直接可复用的管理复盘提问见[项目复盘提示词](project-review-prompt.md)。

11 月 16 日的[交接草稿 #32](https://github.com/TheDeadly-cat/hakimi-jiaoyi/pull/32)记录了较早的因子页面补丁。当时的启动缺口属于那个版本。这里报告的运行结果对应后续本机隔离版，公开交接文件的范围见下方清单。

## 原黑金交易台首页

[原首页的同屏组件、挂载元素和加载顺序](terminal-home/README.md)涵盖自选、K 线、报价、盘口以及研究与模拟区。九份脚本或样式与隔离版原件一致。盘口脚本移除了两份内嵌行情快照，缺少行情时走原有的提示分支。原终端主程序和同源服务负责提供数据与保存记录。

## 模拟交易内核

以下两份 Python 文件来自隔离版的 `exchange_terminal/services/`。使用 Python 标准库即可在本地检查。

| 文件 | 作用 | 隔离版文件 SHA-256 |

| [terminal_sim_order_fees.py](kernel/terminal_sim_order_fees.py) | 按 2026 年 11 月 24 日记录的富途模拟规则计算单笔假设成交的费用组成。账户真实收费、历史适用期及券商逐项舍入仍需凭证。 | `51b8e69c2e138f668f9be51ee971ffbdf6e1a2886ad2f499a85284bd1a0ba524` |

在本目录的 `kernel` 子目录运行 `python -B -m unittest -v test_kernel_snapshot`。四项合成检查覆盖股票费用上限、期权价格费率分界、单快照限价单的余量，以及拒绝使用晚于模拟时间的盘口。

隔离版的桌面运行环境和用户记录保存在本机。GitHub 上的源码交接供审阅和分项复核，不能从此目录直接启动整套桌面产品。
