# 新手第一次使用

新的原终端候选 **0.7.0.dev1** 请使用[原终端候选首用说明](windows-original-terminal-candidate.md)：解压完整文件夹后双击 **HakimiTrade.exe**，在同一窗口新建研究、核对数据、保存、明确运行并重开结果。候选实际验收状态见[交付清单](astra-backlog.md)。

## 旧 dev5 的首用说明（历史）

以下 `HakimiWorkbench.exe` 和“开始与继续”说明仅对应旧 `0.6.0.dev5`，保留给旧包使用者；不作为新候选的推荐入口。

这是一份使用模拟本金的量化研究试用工具。它准备数据、执行明确规则、计算历史结果和交易成本；深入的公司与市场研究继续由研究项目承担。试用包不连接券商或下单。

## 打开试用包

取得维护者提供的 Windows x64 试用 ZIP 后，将整个压缩包解压到一个新文件夹，双击 `HakimiWorkbench.exe`。程序自带运行时，不要求输入命令。请保留完整文件夹，不要只复制 exe，也不要覆盖旧版本。

打开时会检查程序文件。主页面显示简单版本号；需要支持时，展开“版本与诊断”或打开窗口的“工作台”菜单，选择“复制诊断信息”。数据与日志位置也可从菜单查看。程序文件与数据目录分开保存，旧入口和旧工作区保持原样。

这是开发试用包，签名、干净新机验收及具体安装证据以随包说明和验收报告为准。不要把本机工程验证当成真实新手测试或正式版本发布。

## 先体验一个示例

1. 在“开始与继续”点击“开始示例体验”。软件载入固定的虚构日线；此时只保存数据，没有回测。
2. 在模板菜单选择“双均线操作示例”。确认数据明确标为虚构示例，再阅读均线、仓位、止损止盈、手续费和滑点。
3. 核对评分日期、名称与模拟本金，点击“确认设置并保存任务”。预热数据只用于计算指标，不计入评分区间。
4. 点击“运行这次回测”。看到保存的结果后，阅读收益、回撤、成交笔数和完整买卖次数。
5. 同时阅读“当前样本不足”等证据说明。运行成功表示程序完成计算，不能推导长期表现。示例亏损也不是程序故障；虚构数据不能作为真实股票收益依据。

可以随时返回选择数据，或跳过引导进入原任务工作台。原有配置和导入入口继续提供。

## 添加自己的股票

在“开始与继续”点击“添加第一只股票”，输入美股代码并明确选择20、60或120个完整交易日。这里的数量包含指标预热，实际评分天数更少。点击“获取并检查数据”才会联网。

检查后核对代码、公司名称、交易所、币种和数据范围。仅当检查可保存且你确认证券是所需的美股普通股时，勾选确认并点击“确认证券并保存本次数据”。程序保留来源原件与检查记录，不要求你制作JSON文件。来源仍未获独立认证，证券卡不是独立证券认证证明。

之后明确选择“入门5/10”或原标准模板，再确认设置并运行。入门模板与原20/60默认是不同的明确选项；软件不会按结果替你换参数或缩短区间。预热不足时，应由你选择更长支持区间或另一模板。

有分红、拆股、缺失日线、价格口径不一致或不支持的交易日历时，本版本会停止保存并说明原因。此时可以保留检查记录、回到示例体验或查看支持范围，不能把停止提示当成已取得可用数据。高级JSON/CSV导入保留在“数据与研究”的“高级导入”中。

## 看懂第一次结果

| 页面信息 | 代表什么 |
|---|---|
| 本次回测已完成 | 本次明确设置的计算已经完成，并保存结果 |
| 净收益 | 该评分区间、该本金和成本设置下的模拟收益 |
| 最大回撤 | 保存结果中权益从高点回落的最大比例，不代表未来损失上限 |
| 成交笔数／完整买卖次数 | 买卖成交与完整往返是不同数量；只有买入不等于完成一次买卖 |
| 当前样本不足 | 不能用这份短样本判断长期表现或可靠年化收益 |
| 没有模拟成交 | 可能一直等待，也可能有买入判断但未形成成交；看紧邻说明和信号原因 |
| 成本比较完成 | 已计算指定成本与参考结果，不表示策略通过有效性验证 |

“比较交易成本和参考结果”沿用已有保存包。每项基准使用独立本金；25%仓位策略与100%买入持有不同，不能简单宣布谁更优秀。查看已存验证不会自动重算。

## 第二天继续

从同一个 exe 打开。“继续上次”根据工作区回执展示已保存到哪一步，而不是依赖浏览器端口。点击“查看上次保存结果”只读原结果；刷新也不会再次回测。原有任务和结果始终可从“任务工作台”查看。

“今天可以做什么”显示已保存股票及数据截止日。点击某只股票的入口只跳转到检查表单，随后明确点击检查按钮才联网；未检查前不能断定有新数据。

采用新数据时，先核对来源和历史修订，再保存本次数据、用新数据建立新任务版本。原参数、旧版本和旧结果保留；新版本不会自动运行。发现原连续组合不兼容时，保留旧账本；新建组合从新的模拟本金和空仓开始，不迁移旧持仓。重开后也不会自动恢复本地观察。

如果页面提示“保存状态还没有确认”，请先刷新核对原回执。它可能已经保存；不要重复提交或重新运行。常见错误会提供下一步按钮，完整错误留在技术详情。
