# 哈基米交易：产品方向与里程碑

项目最终交付交易量化工具。本项目负责把规则固化为策略模块与配置，完成量化验证、风控、运行与受控执行；交易分析项目负责深度市场研究、观点和研究依据。输入以明确的证券、日期、来源、可用时点和内容身份接入；分析观点不会覆盖正式策略配置。

研究内核继续隔离，复用现有回测、记账、风控和快照。独立执行层负责账户与订单权限。调整产品定位不修改历史权限，不将研究结果当作订单授权。

| 里程碑 | 建设内容 | 完成标准与当前范围 |
|---|---|---|
| M1：现有能力产品化 | 定位、正常导入／续接／迁移、统一安装入口、策略接入接口准备、同一候选产物验收 | 已交付并经 PR #19 集成；dev4 存档，三个流程缺陷保持关闭 |
| M2：统一策略工具 | 统一策略规则管理；统一证券、日历、价格口径、公司行为和事件时点入口 | 当前仅 M2-1：受支持参数／风险配置、任务版本与状态、相同数据／评分／本金／成本条件下的保存结果对照。复用三个现有策略和同一引擎；更广数据、公司行为、内容规则另行扩展 |
| M3：受监督信号工具 | 账户／组合级风险、观察列表、增量输入、去重、过期判断、异常和运行状态 | 多策略不重复占用同一现金；全局停止可查且恢复有条件。新监控／观察窗口须单独恢复授权 |
| M4：受控模拟交易工具 | 复用富途适配器及 SQLite 状态机，衔接信号、风险、意图、授权、提交、查询、撤单和对账 | 经单独授权完成可追溯模拟闭环，Unknown 不重发，账户不一致停止新增风险。真实交易另设准入 |

M1 不包含策略寻优、新一轮市场研究、组合资金管理、新监控或账户操作。其策略目录是对已有实现的适配接口准备，并不意味着 M2 的完整策略管理已经完成。

当前数据与成交边界：美股正股常规时段日线；身份稳定、声明完整且无公司行为的窗口；碎股、比例费用、固定滑点和期末市值为研究近似。有效杠杆为 1，借款、保证金、强平、做空和期权不受支持。拆股、分红记账及其他来源按独立扩展实现，未支持情形继续拒绝。

M2 数据入口将统一证券身份、币种、交易日历、公司行为覆盖、事件时点、价格口径与内容摘要；回测和后续信号计算使用同一身份。缺失、过期、损坏或不支持的输入应有明确停止／排除结果。拆股和分红、股数单位、费用及成交约束须在实现后逐项验收。

M3 的账户／组合风控包括总仓位、单证券占用、重复信号、并发资金预留、组合损失限制和全局暂停；单策略不能绕过共享约束，停止原因及恢复条件须可查。运行层接入同一策略逻辑的增量数据，支持明确观察列表、信号去重、过期判断、最后一次成功时间及当前可用状态；先离线演练断网、超时和重启，真实观察窗口另行授权。

M4 复用已有富途适配器及 SQLite 状态机，逐步衔接策略信号、风险、订单意图、授权、提交、查询、撤单、恢复和对账。订单路径、账户状态和费用会计分别验收；不存在的供应商账单接口标为不支持，缺失费用保留未知。实际模拟须明确恢复，未知订单不重发、账户不一致不新增风险；真实交易另设准入。

当前开发基线为 PR #19 已合并的 main `17b2c15891aab7caf30dbb1addbb1f495f92dea0`，内容树与受审 `669b348` 一致；实际 main [九项检查通过](https://github.com/TheDeadly-cat/hakimi-jiaoyi/actions/runs/37912896005)，Windows 安装后 209 项通过。M1 存档候选 `0.3.0.dev4` 仍绑定原构建 `ac8c77b`，没有重签。正式 Release 仍为 v0.2.1；旧 r3、NVIDIA 两事件八次对照及原阅读验收保留原身份。

M1 已结案，进入 M2-1：候选 `0.4.0.dev1` 完成正常配置入口、不可变版本／启停和条件对照，同一产物安装与使用验收单独记录，见[任务说明](strategy-task-management.md)。多任务各自独立本金，不是共享资金组合；评分区间不因预热暗改，买入持有与主动策略的仓位／止损／退出差异必须显示。保持 Unknown／T3、旧观察、客服邮件和新监控原状态，不重跑已结案研究。主分支合并、正式发布和订单均需相应单独授权。
