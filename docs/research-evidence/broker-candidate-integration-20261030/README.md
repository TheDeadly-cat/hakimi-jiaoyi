## 绑定与停止

后端从原报告读取不可变的策略、参数、行情、版本和报告校验值，不接受浏览器提供的“可信报告”。保存意图前再次读取并核对；不同证券、过期、超额度、被停止或绑定已变化均不能准备新意图。

“停止准备新意图”有独立请求入口，绕过普通任务队列和研究锁，使用短事务保存控制回执；跨实例仍以同一控制记录为准。在途准备遇到停止或恢复后的控制版本变化便拒绝提交。恢复只恢复本地准备，需要明确确认最近一次停止回执；不会取消券商挂单或恢复外部权限。

回执未知时保留原请求编号，只能查询该请求，不自动重试。历史停止回执和当前停止状态分别显示；重新打开或只读刷新不会生成新的意图或控制操作。控制记录容量保留下一次停止的位置，历史不清除。
