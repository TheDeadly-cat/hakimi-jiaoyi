实际启动器在全新目录中离线安装、验证包与依赖后打开菜单。创建 alpha 时逐项输入参数及风险，运行 v1；通过菜单修改本金保存 v2 并运行；暂停后拒绝运行，退出／重开仍为暂停。选择 v1 保持暂停，经启用后复用原报告；初始版本、封存快照及原报告四个文件的字节不变。复制并切换为买入持有，同时运行既有公告过滤任务，正常菜单可以比较三策略。请求止损 0.04 超过最大距离 0.03 时明确停止；状态链不新增提交，两个合法版本及失败准备目录保留，未自动激活。

之后将代理整个候选目录（包、运行环境和工作区）迁移到另一目录，旧路径实际不存在。同一启动器仍验证安装并打开菜单，版本、状态、历史、重放、原报告恢复和比较通过；迁移派生新页面，原报告未改写。这是同一 Windows 主机上的实际迁移，不声称跨计算机环境已验收。独立安装流程也覆盖工作区单独迁移、三份报告重放和恢复。原始菜单输入／终端记录保留在本机私有证据，公开回执只记录其校验值。
