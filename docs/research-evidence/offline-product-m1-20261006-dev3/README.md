旧版首用暴露“查看报告只给路径、依赖浏览器”的缺口。Windows computer-use 因无法确认当前 URL 中止，内置浏览器也禁止 file 协议；没有绕过这些限制。新版本直接读取核验后的结构化结果，不执行 HTML 或浏览器操作即可完成正常查看。菜单 11 的可选浏览器请求有五秒上限，失败／超时回归通过；真实浏览器展示未验收。

[查看范围](browser-and-view-scope.json)保留该限制。HTML 的 `render_run` 源函数与旧受验收 wheel 完全一致，原两报告的布局／展开交互证据保留为历史范围。新首用证明来自实际终端结果，不把旧截图或用户阅读反馈改签为新首用。
