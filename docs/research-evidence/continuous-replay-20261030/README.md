# 同窗逐日模拟与中断恢复

在“执行演练”进入“逐日模拟”，可以从已完成的原策略研究创建独立历史模拟，按保存日线明确处理下一交易日，查看现金、整股持仓、最后处理日期与下一日期。重开只读取保存状态，需要核对并明确恢复；恢复本身不处理下一日。

这是从预览中的起始日建立的新历史模拟，不是从原报告结束日接着运行。用户明确填写模拟名称、初始合成现金、固定股数、费率和滑点，再确认模型差异。费率以百分比输入和展示；内部仍保存精确比例字符串，例如 `0.1% → 0.001`，超出小数精度拒绝而不舍入。

## 规则、数据与时钟

模型身份为 `HISTORICAL_REPLAY_WHOLE_SHARE_NEXT_OPEN_V1`。原九策略的真实信号函数保持原样；前一根收盘产生信号，下一完整日线开盘按明确滑点和费率合成成交，再用更新后的仓位计算当根收盘信号。第 80 根收盘作为默认起始信号，与原引擎 `evaluation_start - 1` 的边界一致；长窗口由真实参数要求决定。

新模型采用固定整股、多头、独立现金，不执行柱内止损或止盈。原回测的仓位比例、分数股及盘中保护不自动继承，不能把两种模型的收益当作等价结果。现金不足明确拒绝这笔合成买入；没有下一完整根则等待，不补成交或强平。

准入只接受可核验、当前规则代码仍一致的原策略完成报告。行情必须带已保留的原 canonical 日线和日历原件，再核对证券、币种、价格口径、OHLCV、日期、开收盘时间、完整状态和无公司行为区间。普通本地缓存缺这些原件时不推测日历。保存的市场资料仍不代表来源真实性已独立认证。

事件时间来自原保存交易日历；实际操作时间另记。每次只向信号函数提供截至该根的前缀。采用更多已保存数据需要明确确认，必须保留已处理前缀的价格、量和时钟；历史修订不能悄悄延用原模拟。采用数据不获取行情、不推进日期、不产生交易。

## 回执与恢复

创建、起始信号、下一日、采用版本、暂停、核对和恢复分别操作。暂停走独立入口，不等普通任务或研究锁；源码变化后仍能读取原账本、暂停和核对，新的计算继续要求当前来源与代码核验。

发出请求前，在当前工作区对应的浏览器存储中保存原请求、账户、动作和完整 payload 摘要，并读回确认。正常请求与控制请求分别保留一个待核对记录。匹配的成功回执先显示保存事实，再刷新辅助区域；后置读取失败不改成操作失败。

丢失回复时只查询原编号。回执必须匹配工作区、账户、请求、动作和完整 payload 摘要才清除待核对记录，不能从 `NOT_FOUND` 推断未执行。仅事务中已证明尚未写入且原 ID 没有既有/待决记录的过期 head 拒绝，返回明确 `REFUSED_NOT_APPLIED`；用户可以重新读取后明确操作，不自动重试。泛化错误、源码门禁失败、IO 或提交异常仍保持 UNKNOWN。该明确拒绝的回复若丢失，也不自动推断结果。

账本校验后核对会保持暂停，不重新计算；恢复必须另行确认。容量达到上限时保留历史并停止新增业务步骤，有限控制余量用于暂停/核对，不清理旧事件换取继续。关闭只释放空闲句柄，不新增取消或已核对记录；计算中的句柄拒绝关闭，现有主程序先等普通任务结束。
