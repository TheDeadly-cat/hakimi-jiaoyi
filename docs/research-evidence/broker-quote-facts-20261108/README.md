# 原后台的请求构造与查询资料保存

已有连接可以收取响应，但后台没有正式的 protobuf 请求构造入口，三类行情查询的响应也不能进入原账本的结构化资料链。本批沿用原协调器、worker、停止控制和 `VERIFIED_RESPONSE` 事件：按已保存范围构造请求，核对响应所属请求及证券，保存可观察字段，重开按原操作 ID 只读找回。

`encode_request()` 只构造既有协议允许的字段，检查数字转换是否改变原金额，再走原请求校验。`from_verified_bindings()` 使用原私有加载器核验的类，并核对它们的包与 SDK 身份；这证明代码和报文来源，不授予外部访问权限。普通的假协议对象测试与实际锁定 protobuf 类验证分别记录。

| 查询 | 保存内容 | 不据此推导 |
| --- | --- | --- |
| 全局状态（1002） | 全局美股状态、服务器登录状态、版本、服务器时间及可选连接 ID；连接 ID 如有必须匹配原 quote 握手 | 目标证券当前可交易、行情权限、价格时间或下单授权 |
| 证券资料（3202） | 精确市场/代码、证券 ID、正股类型、每手股数及可选退市/交易所状态 | 币种、完整数量规则和交易资格 |
| 快照（3203） | 精确证券、停牌标记、价格、买卖价、原更新时间及可选时间戳/股票状态 | 合法订单 tick、全部字段的更新时间、报价新鲜度或未来收益 |

缺字段保持缺失，未知状态保持未知。匹配状态只表示原请求范围与存在性符合；现金、归属持仓、费用、成交和交易资格不会由这些资料自动产生。语义依据与版本限制见[官方字段核对](official-field-review.md)。

整合验证使用自持动态本机端口及明确标注的虚构响应。原 ACTION 先持久保存再进行 IO；错证券响应保留原字节，但不生成匹配事实。重开读取第一次保存的请求字节和同一操作 ID，不重新握手或查询。人为推进接收时间的重投影案例单独标记，不冒充网络真实延迟，也不改写旧事实的接收时间。

本批后续源码不在已公开的 [r7 试用候选](https://github.com/TheDeadly-cat/hakimi-jiaoyi/releases/tag/v0.7.0.dev3-r7)中。借用 r7 私有解释器执行当前源码探针，不等于 r7 包内功能、原生首用或生产 bootstrap 验收。默认生产入口、`PackageWorkerSpec` 准入和九项外部权限继续保持原有拒绝边界。

下单前核对仍需补齐目标证券市场状态、报价时效、合法价格/数量、行情权限、可预留现金与 owner 持仓、费用及生产授权装配。本批没有接入一个可绕过的可选 submit 检查，没有连接 OpenD 或实际账户；本批查询链不创建订单或研究运行。

## 验证结果与原件范围

- 一次[完整 terminal 检查](full-terminal.json) **913/913 通过**，零失败、错误或跳过，耗时 314.735 秒。使用独立环境实际安装本工作树，8 个改动源码输入前后哈希一致。[原日志](logs/full-terminal.log)保留。
- [真实 protobuf 独立检查](actual-protobuf-summary.json) **4/4 通过**，测试段 334.956 秒、外层 357.326 秒。原私有加载器加载锁定类，原 supervisor/worker 运行，连接仅到自持动态本机端口。[四个案例](actual-case-index.json)、[原日志](logs/actual-protobuf-full.log)及[独立只读复核](independent-review.json)分别记录。
- 请求构造定向 50 项、资料投影/原记录定向 64 项、合成协议 worker 4 项均有保留记录；这些与完整检查重叠。单个真实正例诊断也与最后四项重叠，不能相加为独立覆盖。
- 私有检查核对包 manifest、实际加载依赖闭包及当前源码输入；**不是对 r7 全包再次逐文件验收**。三条查询恢复使用原请求字节；测试装配仍会局部构造一个未发送的 init 请求，不声称恢复过程完全没有编码工作。

[历史尝试](retained-attempts.json)保留：合成夹具首轮误读 snapshot 字段；真实首轮因 Windows 审计命令形式误读而未启动 worker；下一正例因测试的 12 秒 READY 等待不足而在输入/连接之前请求停止。修复只涉及测试装配及有测量依据的独立等待预算，没有放宽生产 supervisor、原请求时限或隔离加载器。

仓库保存紧凑摘要、实际请求/响应字节、worker IO 次序摘要、原件哈希清单、最终探针脚本和日志。完整原 SQLite、副本文件与原加载清单仍保留在本次外部证据目录；案例中的 `retained-artifact-index.json` 明确指向该外部原件范围，不表示其中所有文件都已复制入仓库。目录字节清单为 [SHA256SUMS.json](SHA256SUMS.json)。
