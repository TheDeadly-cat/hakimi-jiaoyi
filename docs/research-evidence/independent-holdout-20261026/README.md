[项目暴露审计v2](exposure-audit-v2.json)核对2175份元数据、112个旧终端及备份数据库、70个本地引用/180个提交，保守排除两标的整段已取得数据2026-05-19至10-22；[匿名文件归属补件](anonymous-csv-attribution.json)逐一收束18组CSV，候选区间未解决重叠为0。旧v1审计及脚本保留。取价前[54项定向检查](preacquisition-checks.json)通过，全部使用合成数据；不与旧安装套件计数相加。

选期只依据已使用范围和交易日历。已经取得的原始行情覆盖也全部排除，不因其部分日期未进策略就认定未见过。冻结后禁止按收益、成交数量或数据质量重新选期；合格的负收益或零成交照实保留。来源完整性或程序完整性失败时保存停止记录。

取价前协议和程序先提交到 Git。取得时间、请求、原始字节与哈希随后独立保存，不回填到封存协议。实际运行通过原工作台创建独立输入和任务；成本及基准、观察器复算分别计数，不将验证复算说成零计算。

“独立”指在明确审计范围内未参与项目开发和调参的留出样本，不是统计独立性证明。采用十月已固定的规则测试更早月份，仍是回顾性检验，不是时间顺序上的样本外预测。事后取得的行情也不构成当时可取得相同字节的证明。这些边界与 [scikit-learn 的数据泄漏原则](https://scikit-learn.org/stable/common_pitfalls.html)及[时序划分说明](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.TimeSeriesSplit.html)一致。

证据分别核对：项目暴露审计、取价前承诺、固定参数未变、策略逐日前缀、完整结果与成本、桌面关闭重开、旧记录保全及精确提交的 GitHub 检查。单独的前缀观察器只证明策略输入边界，不替代盲测资格审计。
