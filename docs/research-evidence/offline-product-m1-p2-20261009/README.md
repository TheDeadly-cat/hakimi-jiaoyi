# PR #19／M1 三项流程修复

本轮针对 1307039 的三项 P2：初始化到持锁间的接管导致重复计算、初始化未封存却留下不可恢复最终目录，以及外部输出保存历史时路径转换失败。旧 dev3 原件、构建、201 项安装后检查与首用证据保留；这些成功不表示新异常时序已经覆盖。

新实现从准备前领取操作系统锁，原运行与恢复使用同一互斥并在锁内检查已保存报告。输入封存和启动记录完整后原子发布运行目录；初始化失败的暂存原件保留，可重新运行原任务。既有残缺最终目录不删除、不覆盖，不按完整运行恢复；可用标准 `run --task ... --output-dir <新位置>` 明确重试。

任务输入、输出与最近运行共用位置解析。工作区内历史为相对位置，外部为明确绝对位置；旧记录保持兼容。菜单历史和恢复同时发现工作区与任务声明的外部输出，无最近标记的失败计算也可发现。

三项修复已完成，新 dev4 通过 209 项安装后检查及真实 Windows 默认／同盘外部／跨盘菜单使用回归。操作者为终端工具代理，不声称用户人工验收了新包。旧 NVIDIA 报告的“能找到，展示清楚”仍只支持该报告阅读。
