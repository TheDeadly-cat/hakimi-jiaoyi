# 第二家公司真实资料：NVIDIA 两财季流程验收

已通过同一个清单入口导入三份 NVIDIA 官方新闻原件，完成财年 2024 第 1、2 季度的来源提取、独立数值核对和只读卡片。公司、事件、版本、范围和输出目录来自 JSON 清单，不在任务引擎中写死。第一次实际导入因格式差异明确停止；针对真实格式补充有限适配后，新版本通过，旧失败包和原件保留。

这是**可复用资料流程的工程验收**。没有新增行情或收益回测，没有人工核准或研究接纳。新公司与新年份并不自动成为未见验证集。

## 固定范围与来源

选样原因是检验与 AMD 不同的财年标签、百分比经营范围和页面日期格式；三个查询的财季在读取查询结果前已固定，未按价格或事后收益选事件。预算最多 6 份官方公开文档，本轮实际进行 3 次采集调用、取得 3 份原件，无自动重试。采集与离线入口分开执行，导入命令本身没有网络权限。

| 原件 | 页面公开日期 | 本次用途 |
|---|---|---|
| [第四季度及财年2023](https://nvidianews.nvidia.com/news/nvidia-announces-financial-results-for-fourth-quarter-and-fiscal-2023) | 2023-02-22 | 对 FY2024Q1 的公司指引 |
| [第一季度财年2024](https://nvidianews.nvidia.com/news/nvidia-announces-financial-results-for-first-quarter-fiscal-2024) | 2023-05-24 | FY2024Q1 实际营收、对 FY2024Q2 的指引 |
| [第二季度财年2024](https://nvidianews.nvidia.com/news/nvidia-announces-financial-results-for-second-quarter-fiscal-2024) | 2023-08-23 | FY2024Q2 实际营收 |

实际采集时间是 2026-09-27 09:28:52—09:28:55 UTC，提取时间单独保存在任务包。正文只标日期，没有精确时刻；旁栏的 2026 年相关新闻日期不会被借来当作历史公开时间。`public_at`、历史模型可用时间保持 `null`。核查窗口前后各留一个日历日容纳日期精度，不声称日期就是精确 UTC 时点。

本轮只查所列季度新闻，没有穷尽新闻归档、电话会、问答、初步披露或全部修订。比较基准是清单中在先公司指引，完整历史链继续为 `false`。表中公司合并收入口径仍为声明及待人工语义核准；来源 URL、SHA-256、时间、引文与各事件关联均见[任务包](packet.json)。完整 HTML 仅保留在本机，没有上传仓库。

|---|---:|---:|---|---|---|
| FY2024Q1 | 7192 | 6500 | 6370—6630（±2%） | 686.50—697.50 | 数值高于所列在先中点 |

## 能复用的操作与核验

[操作说明](../../equity-source-task.md)提供 `run`、`verify`、`report` 三个离线操作。[清单模板](manifest.example.json)保留实际证券、事件和来源摘要，路径改为用户可填的相对目录；它是可移植模板，不冒充实际执行清单的原字节。实际完整任务目录内保留原执行清单、原件与前身包，`packet.json` 记录其身份。

正常资料、歧义表格、错单位、错财季、已知披露缺失、覆盖差异、修订选择、新版本不覆盖、缺少公告前价格、仅日期不能借造时刻、人工声明不升级权限，以及清单子进程入口均有行为检查。共 89 项定向检查通过：30 项新流程和 59 项旧合同。真实原件另外通过实际命令与独立数值核验，不能把它们混成独立样本数量。

真实格式需要的适配包括：FY24 两位财年、正文 `article-date`、美元符号与数值分属不同单元格，以及排除非 GAAP／全年表。AMD 原固定规约和审计模块未修改；共享卡片默认输出仍逐字节复现原报告。没有改动共享回测、风险或账本实现。
