## 健康状态不能只看退出码

旧窗口53次包装启动均有结束回执；本次重新核对其中没有非零退出、没有退出0但结果状态/2条观察/2条重放不符的记录，也没有未结束包装回执。这只覆盖已记录调用，不能把另12个cutoff当作成功。包装器部署之前的历史进程起止与失败仍有取证限制。

建议后续监控明确区分：`RESULT_VALID`、`EXIT_ZERO_RESULT_INVALID`、`DUE_WITHOUT_START`、`START_WITHOUT_END`、`FAILED`、`LATE`、`DUPLICATE_VERIFY`。运行进程退出0与某个cutoff取得有效结果是两层事实。

旧窗口的49次DONT_NOTIFY与4次NOTIFY都是程序决定。没有用户确认或独立投递回执，全部实际送达状态仍为UNKNOWN；会话中出现最终通知文本也只能证明文本被生成，不能证明用户收到。

TaskScheduler/Operational当前未启用且没有可用记录，无法复原过去的OS任务调用，也没有为取证开启日志。System日志最早保留至05-02，NetworkProfile日志最早至05-29，覆盖这次查询日期；但日志无记录不等于没有事件。NetworkProfile仅显示本机网络配置连接，不证明OKX可达或不存在短暂DNS/TLS/链路故障。
