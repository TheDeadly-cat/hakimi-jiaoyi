# 两项受控规则诊断：保留机制结论，本轮不晋级

Dual MA 去掉固定止盈后，正常成本连续收益从 −6.07% 变为 +6.77%，但回撤、敞口和成本同时上升，后续历史表现及压力成本没有形成稳定优势。RSI 每个连续超卖事件只允许一次入场意图，减少了重复交易与成本，正常成本仍亏损 23.69%。两项变体均停止本轮晋级和追加调参，保留为可复核的研究记录。

这项结论只涉及此处固定规则、BTC-USDT 现货 1h、所列成本与已查看历史；不否定所有趋势或 RSI 方法，也不代表未来交易许可。

## 固定范围与预算

计划在 **2026-09-06 07:22:24 UTC** 冻结，见[完整计划](../../studies/strategy-diagnostics-plan-20260906.json)。四个配置 × 0/1/2/3 倍成本 = **16 条连续轨迹**，另以独立安装环境重放这 16 条轨迹；没有参数搜索或追加历史候选。数据为 2023-01-01 至 2026-09-01 的 32,136 根小时记录，前 72 根仅供上下文，评分从 2023-01-04 开始，共 32,064 小时。

每条轨迹仅初始化一次 10,000 USDT、空仓；跨月、季度保留同一研究核心中的现金、持仓、平均成本、保护条件、挂起信号和必要策略状态。月度及原 16 个边界片段均从这条连续账本事后截取，没有重置资金，没有拼接原 reset 窗口的收益。底层快照是明确标注的本地派生 CSV；[来源链](../continuous-history-20260906/input_derivation_dda2cfd7a0f44e582c9b723a2acf0686480830faa30698b8dca9161701d4f9ae.json)核对原 16 份快照、重叠行和完整范围，不升级提供方真实性结论。

## 规则与旧版兼容

变体使用 `research-experiment-spec-v2`。D1 参数明确为 `"fixed_take_profit_policy": "DISABLED"` 并省略 `take_profit_pct`，拒绝冲突百分比、0、极大值、null或其他伪禁用值。D0 继续使用旧 v1 的真实8%止盈；v1不接受新策略政策字段，旧默认行为保持原样。CLI目前默认示例仍是v1，使用v2时将完整计划中的变体参数放入规范实验文件即可。

R1 参数为 `"oversold_entry_policy": "ONCE_PER_EVENT"`。首次观察到 RSI<30 时开始事件；首次有限 RSI≥30 时结束事件。初始最后一根上下文柱已超卖时可产生一次意图；机会在生成意图时即被消耗，发生在风控判断和成交之前。风控拒绝、部分成交、止损退出以及旧仓位开盘保护取消挂起意图，都不会重置事件；跨统计周期也不会重置。只有后来的新超卖事件才允许下一次意图，持仓中的不同事件仍遵守原仓位与加仓风控。

RSI始终使用原 `indicators.py` 的简单滚动均值定义，未改成Wilder平滑。`backtest.py` 的v6保护顺序、`risk.py`原字节和指标实现均保持不变；[运行时差异](runtime-diff.json)确认36份运行文件中仅实验规约与策略模板两份变化。

## 稳定性、集中度与停止决定

D1正常成本在原16个边界片段中，7段优于D0、5段更差、4段收益率可视为相同；R1为7段改善、9段更差。这里只在描述性计数时将绝对收益率差≤1e−10归为平局，规范JSON仍保留全部原始差值；没有对信号、订单或账本的差异使用该容差。

D1开发期2023–2024连续收益+19.30%，2025至2026年7月底的后续历史区间为−13.99%。已查看的2026年8月贡献416.11 USDT，占最终677.27 USDT净利润的61.44%；去掉该月，整体仅+2.61%。D1正常成本亏损23/44个月，前三个盈利月占正月度损益的48.35%。因此，固定止盈截断部分收益的机制值得保留，但本轮不把D1推进到自动执行或继续扩大参数范围；归档此晋级候选，保留冻结配置与这份可反驳的机制结论。

R1正常成本亏损22/44个月，前三个盈利月占正月度损益的38.58%；2/3倍成本仍亏损46.71%/62.82%。单事件政策减少了交易摩擦，却没有解决正常成本亏损、较低敞口和阶段性退化。本轮归档R1候选，不追加阈值、平滑算法或仓位搜索。

以上集中度只描述连续账本中正月度损益的贡献，不是独立样本检验；各片段共享资金路径，也不允许相加或简单拼接为别的资金曲线。全部2023–2026年8月历史已经被查看，任何基于这里再改规则的研究都仍是开发诊断。独立确认只能来自规则再次冻结后真实未见的未来数据。
