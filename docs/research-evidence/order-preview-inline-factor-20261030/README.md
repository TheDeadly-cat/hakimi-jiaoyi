# 在订单预览内核对历史因子

保存账户或计划后，旧的因子核对按设计失效，但原预览只有“尚未核对因子”的说明，用户必须滚回页面上部。本次让用户在预览旁明确选择历史诊断情景、读取同一保存结果的因子；失败时就地按同一结果和情景重试。

只使用一组控件和一份状态：有预览时移入预览，没有预览时移回上方。选择诊断情景不改变订单方向、数量、价格、参考时点、账户或计划；会清除旧解释、使迟到回复失效，并取消最终确认勾选。来源、账户版本、计划及经济字段变动仍使原预览失效。没有默认空仓或买入，也没有更改策略公式。
