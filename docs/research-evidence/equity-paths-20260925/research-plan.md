# 后续价格路径与退出规则：预先声明的诊断方案

本次只回答：C 的合法入场以后，价格在固定的第 1、3、5 个交易日如何变化；既有止损路径与这些变化有什么关系？对象为原十个 AMD 财报窗口，七个接纳、三个继续排除；没有入场的事件也保留原因。A/B 和 C/D 原报告只读，不重跑、不改参数、不把结果回填原实验。

起点为已有 C 买入所在的下一常规开盘，之前必须满足公告模型可用、首个完整交易日完成且价格确认成立。入场当天计第 1 日，第 3、5 日按交易日历计算，原评分区间之外或原快照不完整时记缺失。不会改成自然日、补入新价格或缩短期限。

每个期限并列原开盘至收盘的价格变化、期间最高／最低价相对开盘的范围、沿用实际模拟入场后现金与数量计算的市值估值，以及原止损退出、费用和已实现损益。市值估值保留入场费与滑点；它不是取消止损后的新回测，没有虚构出场成交或费用。两档成本分别保留，不把重复场景当新事件。

日线无法证明高低价先后、最高价是在止损前还是止损后。严格“退出后”的范围仅使用退出日之后的完整交易日；同日剩余路径保持未知，不给精确持有时间。没有 C 信号就不产生所谓策略收益；三个原排除也不能填零。

固定三个期限全部展示，不按结果选最佳期限、不放宽止损、不搜索参数。输入身份不符即停止；尾段缺失如实标记；无新来源便不扩样。两个不同 AMD 事件最多支持具体路径解释，不能证明信号优势或退出规则的因果效果。机器可核对的冻结定义见 [path-protocol.json](path-protocol.json)。

# 下一项内容研究：同一目标财季的公司指引比较（仅规约）

假设：在既定价格确认条件之外，当期营收相对公司此前对**同一目标财季**最后一份可用指引，是否有可核验的正向差异？它与“下一季指引高于本季营收”不同，也不使用分析师一致预期。此处交付研究定义及取数门槛，不执行新的内容策略。

候选比较为 `(当期营收 − 此前同财季指引中点) / 指引中点 > 0`，保持 C 的时点、成本、仓位和退出规则。实际值和指引必须匹配证券、目标财季、币种、单位、收入覆盖范围及会计口径；前序版本必须在本次公告之前公开，并保留连续修订链。没有可比前序就记缺失，不能拿另一财季代替。

优先取公司 IR、提交文件及修订原文，字段包括实际营收、精度、前序同财季指引中点／区间、各自公开与实际获取／提取时间、版本链、来源摘要及核准范围。已核准十行不重审；新增精确实际值、新指引或历史版本是新增字段，取得证据后另作相应审查。四舍五入值用其精度区间判断；若差值可能跨零，条件为未知，不能补小数使它变正。2022Q3 的初步公告修订链必须单独完整处理。

数据准备先限定原十事件作为已见开发覆盖清单，零新经济回测、零模型调用、零账户操作。缺完整前序、可比口径或合法来源则停止相应事件；不添加替代事件挽救覆盖率，不以收益决定来源。未来未见验证集须在取回价格和观察结果之前另行确定名单、来源预算、成本和停止规则。当前材料不能冒充未见确认集，也不授予交易或部署权限。
