## 固定输入与执行方法

C 在公告模型可用后第一个完整常规时段的已完成收盘价严格高于公告前最后常规收盘价时确认，仅下一常规开盘入场。不搜索后面的上涨日，超出原评分区间就跳过。D 仅多一个条件：已核准的下一财季公司营收指引中点，严格高于当季首段四舍五入的 GAAP 营收。它不是分析师一致预期，也不是“超预期”信号。

沿用原七个快照、评分区间和原 A 的其余风险上限。2022Q2、2022Q4、2023Q3 继续因原 OHLC 差异排除，没有换价、放宽接纳或替换样本。正常费率／滑点为 0.0008／0.0005，两倍成本为 0.0016／0.0010。

执行使用既有 `BacktestEngine`、常规交易时段适配、`RiskManager` 和会计路径。新增工具只生成明确命名的价格确认信号，研究报告采用独立内容研究身份；没有把均线或买入持有报告重新命名。原数值核心仍为 `c5d57ec3…` 的非 editable 安装，源码与环境实测验证通过；新工具各自绑定实际文件摘要。[完整派生结果](study-results.json)含 28 份新报告的摘要指针。

公告由既有 `equity-event-v1` 建立新版本记录，保留原归档与提取时间；用既有完整版本链校验和时点选择。执行只投影两项所需数字，其他已审字段保留在原候选包。指引在通用事件结构中以独立字段名、下一财季和 `NOT_APPLICABLE` basis 表达，再由冻结规则核对原候选的 `REVENUE_OUTLOOK` 语义。收益每股的损失符号没有为了适配数字 token 规则而伪造原文。

120 秒公告延迟按 60 秒采集＋60 秒处理明确拆分；行情完成后延迟 60 秒。这些都是开发模型假设，不能把 2026 年人工核准、取回时间伪装为 2022—2024 年真实接收证据。当前 HTML 的完整历史修订身份未证明，前序指引历史和一致预期缺口仍保留。

- 14 项真实窗口检查证明，关闭内容条件后的 D 与 C 的完整引擎结果字节一致。

- 221 份输入原件前后摘要一致；原 42 份研究未重跑。未新增行情或账户请求，未下单、撤单、发邮件或恢复 T3。

新增工具是仓库内的离线研究入口；现有 r3 预览、正式 v0.2.1、旧 O1 部署与观察窗口均保持原身份。原 O1 可靠性仍未通过。此结果足以关闭本次固定 D3 开发比较，但不支持策略晋级或“内容无效于所有市场”的结论。后续如研究另一项内容条件，应先另立规约；这十个事件不能改称未见样本。
