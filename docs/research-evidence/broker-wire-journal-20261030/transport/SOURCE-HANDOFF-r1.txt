## Public interfaces

- `ScopedTransport(profile, *, factory, clock, gate, sink, codec)`: no defaults. `connect(channel, permit, deadline)`, `exchange(channel, action, frame, permit, deadline)`, `close(deadline)`, `final_summary()` and `budget_snapshot()`.
- The gate exposes `before_connect(context, permit)` and `before_write(context, permit)` context managers; optional `after_write(context, permit, written)` runs after barrier exit. Context keys exactly: profile_id, intent_scope_id, account_scope_id, mode, channel, action, frame_sha256, serial, offset, total_bytes, deadline.
- Factory returns an unconnected handle. `connect(..., timeout=0)` and every `send(..., timeout=0)` are nonblocking. `wait_connected(timeout)` and `recv(maximum, timeout)` run outside the stop barrier. `peek(1, timeout=0)` rejects already-visible unsolicited bytes; `close(timeout)` is bounded by a single profile cleanup deadline. No would-block retry, reconnection, timer or queue.
- `bind_codec_session(profile, *, client_version, client_id, quote_connection_id=None, quote_user_id=None, trade_connection_id=None, trade_user_id=None, broker_order_id=None)` returns immutable session bytes; supplied fields are not proof of authorization.
- `SimulateCodec(profile, session, *, request_classes, response_classes)` requires exact protocol Request/Response full names. `accept_handshake(profile, channel, serial, raw_frame)` admits only the exact response, ret0 and present positive connID/loginUserID, once per channel, same login on both, under a short update lock. Actual requests can then use the accepted session. AES/key fields stay in private evidence.
- Responses preserve raw frame plus bounded HasField projections. Missing fee, currency, tick and source time remain absent/unknown. Request refreshCache=true is not proof that the returned market facts are fresh. Normal result has economic_acceptance=NOT_INFERRED; no journal ACK is produced.
