原导出只保留八份本地原生文件，不能证明研究侧收到结果。现在从已验证且绑定人工接纳的原生运行生成 SHA-256 命名的中文 Markdown，保留原文件、逐时点影响、来源与任务版本的字节身份；界面明确显示“尚未被研究侧接收”，提示使用交易分析既有的房间资料“导入文件”。原公告 URL 不用作量化结果的发布地址。
