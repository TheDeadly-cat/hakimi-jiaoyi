# 股票补证接入与结果使用修复（2026-11-07）

本批源码将已保留的证券资料、公司行为查询原件接入原终端同窗“股票与数据”：选择原检查，读取原件要求，选择四份原件，明确检查；核对证券与限制后，另存一份新行情输入。原来因资料不足而停止的记录保持不变。保存、选用及找回资料均不创建任务或运行研究。

## 来源与权限

- 读取实际留存格式 `futu-retained-sdk-v1`；每个文件至多 1 MiB、四份合计至多 4 MiB。保留原四份行情资料及四份补充资料的原始字节和哈希，逐项核对请求、返回行、证券身份、日期、完整日线及价格口径。
- 新策略为 `FUTU_REPORTED_ACTIONS_FIXED_WINDOW_IMPORT_V2`，只允许已检查的固定窗口内没有报告公司行为的描述性研究。供应商覆盖范围、来源截至时点和真实性仍为未知；导入方的有限声明不冒充供应商完整性保证。
- 区间内拆股、分红等事件继续阻断；区间之后、原报价接收日之前可能影响历史价格口径的事件也阻断。本批未完成真实拆股、分红记账，未通过真实 Futu 原件验收。
- 同一保存请求、跨进程竞争和中断均受持久记录约束。未知结果只能查询原编号，不自动补写或重试。研究输入与交易权限保持隔离，未连接行情提供商、真实账户、模型或订单接口。

## 用户流程修复

- 明确打开已保存的股票研究核心报告后，定位到当前报告标题与订单准备入口；静默刷新、失败读取、过期选择和离开结果页不会抢焦点，读取不会重算。
- 空工作区没有旧数据库或旧报告时显示中性说明；实际损坏、身份或读取错误仍提示。
- 补证库异常时保留已独立核验的行情，单独提示补证信息待核对；补证操作本身仍拒绝执行。
- 用户切换行情后，可再次明确选用先前保存的补证输入；自动保存回调的防重复处理不吞掉用户的明确选择。
- 页面加载、受保护的本地路由、正式包模块清单、打包内容与完整测试入口均已接入。
