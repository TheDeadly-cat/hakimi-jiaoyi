## 修复行为

- 仅当一份在先披露能证明晚于全部其他来源时采用它。精确时间比较 UTC；同日混合精度或并列时刻保留 `AMBIGUOUS_PRIOR_ORDER`。明确更晚的来源可解除较早来源之间的歧义。
- 数值核对 `PASS` 与顺序状态分开，未知时保留正式值、全部在先值和理由，比较及最新来源为空。数值高于和价格交集不会把该事件计为机会。
- 报告复用 `hakimi_research.reporting` 的原子、不覆盖文件发布。中断后可补缺；冲突文件保持原样，报错而不覆盖。HTML 最后发布；这不是整目录断电事务保证。
