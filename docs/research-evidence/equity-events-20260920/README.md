## 输入与预算边界

目前新窗口已接纳行情数为 **0**；价格、证券身份与每窗口完整公司行为证据仍待取得。若有拆股／分红，现有引擎不支持相应持仓会计，必须保留排除及偏差；覆盖未知则保持阻塞，不能只因 `get_rehab` 空列表就宣布没有公司行为。2022Q4 没有可用事前日程时可以单独报告 A／基准，但 B 必须 NOT_RUN，缺失事件仍留在十个分母里。

成本预算为每事件 A/B/基准 × 正常/2倍共 6 格，最多 60 个结果，无参数搜索。每事件独立从 USD 10,000 开始，不把重叠窗口收益累加成连续组合。缺少财季、单位、倍数、币种、会计口径人工核准，C/D 内容策略继续 NOT_RUN；没有一致预期快照就不生成“超预期”。

## 离线入口

`tools/equity_event_diagnostics.py` 复用已安装研究包。每次仅接受一个已接纳快照、原价格规格、日程上下文和该窗口固定事件清单；输出目录必须新建。原行情、原文、完整报告及轨迹保留本机。

```powershell
python tools/equity_event_diagnostics.py --snapshot <snapshot.json> --spec <price-spec.json> --event-context <context.json> --expected-events <events.json> --output-dir <new-local-directory>
```

事件清单是 JSON 数组，每项至少包含 `event_id` 与 `scheduled_date`。可选的 `actual_release_at` 必须有时区及 `actual_release_source`；缺失则跨公告持仓保持 UNKNOWN。日内公告不凭日线撮合时间猜测持仓。事件清单仅是统计分母，不进入历史策略输入。输出同时保留原始意图、可干预意图、实际拦截、日程延迟缺口、正常与压力成本和同期间基准，不选择性删除结果。
