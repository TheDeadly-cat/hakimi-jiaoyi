# 从候选策略继续已有研究

选择策略后先只读查找已有完成研究，避免重复填表、保存和运行。匹配同时核对原生报告身份、输入与原件摘要、历史截止日、规则、完整原始参数、指纹、引擎源码校验值及指标合同；旧兼容参数也参与比较，不按名称或股票代码猜测。

- 唯一匹配且索引完整：重新读取同一报告，核对列表身份和完整配置后直接打开。
- 多份匹配或部分记录未读出：列出各份版本、时间、本金、执行风险和费用，要求明确选择。候选没有这些成本和风险条件，因此只称“行情与规则相同”，不默认挑最新或表现最好的一份。
- 无匹配：提供独立的新建草稿按钮，点击后才带入参数；保存、运行仍需明确操作。读取错误不被解释为“从未做过”；详情失败只重读原结果编号。
- 修改行情、参数或候选会使列表和详情的迟到回复失效。新建或修订草稿会清掉旧保存卡片，历史完成事实保留。
