## 打开与第一次研究

1. 把整个 ZIP 解压到新的文件夹，保留全部文件，双击 `HakimiTrade.exe`。不要用它覆盖旧 dev5 文件夹。
2. 在研究页的“工作区与旧结果”查看程序版本、构建提交和当前数据位置。默认新数据在 `%LOCALAPPDATA%\HakimiTradeTerminal\workspaces\default\runtime`。
3. 没有真实行情时，可明确点击“准备虚构教学示例”熟悉操作；示例始终标明虚构，不是市场证据。使用“新建研究”选择规则；例如两个双均线选项分别按均线当前相对位置、当日上穿/下穿判断，不能因同名而互换。
4. 核对股票、数据、规则和费用。原终端九策略至少预热 80 条完整数据，还需两条用于执行窗口；长周期参数可能增加要求。界面显示已有、预热、可评分条数与区间。股票研究核心使用自己保存的规则要求，不套用原终端的 80 条。
5. 保存后先确认任务名称和版本，再点击“运行这次回测”。保存、看详情和切换页面都不会自动计算。运行中不要重复点击。
6. 完成提示会先确认结果已保存。辅助记录或详情读取失败时，使用“重新读取”查看同一结果；这不会重算。历史 UNKNOWN 保留，不自动补齐。
7. 结果摘要展示保存的股票、规则、区间、本金、成本、成交和持仓。缺失字段写明“未记录”；零成交仅按原记录解释，不代表策略有效或无效。“在行情图表复盘”使用原冻结数据。

九个原策略的参数按标注单位显示，例如动量阈值输入 `1.5%`，任务中仍保存原始比率 `0.015`。修订新建版本，旧报告和原参数保持不变。AI 参考会分别核对数值行情与规则参数；旧分析缺少的信息保持未知，匹配不代表来源已认证，也不替用户选择参数。

## 关闭、重开和旧结果

- 默认关闭窗口即退出；研究尚忙或后台退出未确认时保留窗口并说明原因。只有明确勾选“关闭窗口后留在托盘（后台继续运行）”才会常驻；菜单“退出哈基米交易”结束本程序拥有的后台。
- 同一安装与工作区重复启动会聚焦已有窗口。若端口被不匹配的程序占用，提示冲突并保留对方进程。
- 重开同一程序使用同一新工作区。在“全部策略任务与版本”和“全部回测结果与复盘”继续查看；不会因打开结果而重算。
- “查找已有工作区”可选择已知原终端或旧 dev5 工作区。这里只读取、校验和展示旧记录；不会搬迁、改写、重新运行或把旧引擎结果当作新结果。不能校验的记录明确标为仅元数据。

旧 dev5 的入口仍为 `HakimiWorkbench.exe`，它的 `0.6.0.dev5`、工作区与验收回执保持原身份。新候选不改变旧安装。

## 范围与复核

候选默认本地模式；研究、历史回读和离线样例不会调用付费模型或券商执行。“执行演练”使用独立本地合成账户，接受响应不代表成交。公开日线只在明确点击检查时请求一次；查看旧记录不获取。原外部模拟、实盘和券商订单权限保持关闭，不能从本地工程通过推导已完成外部验收。

独立试用者应不接受开发者现场演示，自行完成“选择研究→核对数据→保存→明确运行→看懂结果→关闭重开”，记录实际求助点。没有试用者时单列等待，工程和日常功能继续推进。

开发者从干净提交运行 `tools/build_windows_terminal.py`。它使用锁定的缓存运行时、`tools/requirements.terminal.lock` 和依赖 SHA256 清单，生成完整资源清单；包内启动重新检查资源和解释器，拒绝丢失、改变或额外模块。开发探测包的 DIRTY 标签不能当作最终候选验收。
