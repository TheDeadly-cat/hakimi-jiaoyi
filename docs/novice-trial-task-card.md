# 独立新手试用任务卡

状态：待真实试用者执行，尚无通过记录。试用者应未参与本项目开发；开发者、代理操作和自动化检查不能替代这次试用。

## 主持人准备

记录实际候选版本、构建提交、bundle ID、Windows 环境和独立试用工作区。当前已构建版本见[候选说明](windows-original-terminal-candidate.md)；不要把更新的 GitHub 源码能力算到旧包上。先保全工作区和旧安装，将新写入放在独立试用位置，只打开这一个程序。

本次使用程序内明确标注的虚构教学资料或已保存、允许使用的输入。只建立新任务；不重跑历史 UNKNOWN/T3，不授权行情请求、模型或真实券商。若数据不足或规则不支持，让试用者按界面理解处理，主持人不要暗中补数据或换结果。

不演示按钮，不代点，不在受阻时直接告知操作路径。可以重述任务目标。试用者求助、理解错误或决定停止时，记录原话和已到达的页面；不要用事后讲解改写首次表现。

## 给试用者的任务

请在程序内选一项可以研究的股票资料和策略，确认数据是否足够，保存一个你能辨认的新任务，并明确运行一次回测。不要重复运行同一保存版本。

然后说明：你研究了什么，是否完成，结果保存在哪里，发生了多少笔交易，你认为这份结果有哪些限制。请尝试找到对应的图表。

最后关闭程序，再次打开，找回刚才同一份任务和结果。说明你是否需要再次运行才能看到它。如果任何一步不清楚，直接说出你想找什么、看到了什么，可以随时停止。
