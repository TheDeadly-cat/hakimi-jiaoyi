# 哈基米交易：首次使用

本说明随同目录的 `HakimiTrade.exe` 一起交付。当前候选版本见 `README.txt`；程序内“工作区与旧结果”显示版本、构建提交和数据位置，完整文件身份保存在 `terminal-manifest.json`。本包尚未作为正式 Release 发布。

## 打开并完成一次研究

1. 将整个 ZIP 解压到新的文件夹，保留全部文件，双击 `HakimiTrade.exe`。不要覆盖旧安装。包内已有运行环境，无须自行安装 Python。
2. 在同一窗口选择股票与已有资料。首次获取日线需要明确点击检查；核对证券、日期范围、来源和价格口径后再确认保存。资料不足或来源异常时，按界面的原因处理，不把检查失败当作已保存。
3. 没有可用真实资料时，可以使用明确标注的虚构教学示例熟悉研究流程。虚构资料和结果不代表市场表现。
4. 在“新建研究”选择规则，查看实际条件和数据要求。数据是否足够由所选规则决定；名称相近的规则可能有不同买卖条件。参数按界面的百分比、基点或天数填写。
5. 保存后确认任务名称和版本，再明确点击“运行这次回测”。只保存、切换页面、查看结果不会运行；运行中不要重复提交。
6. 完成提示会先确认结果已保存。摘要展示股票、区间、本金、费用和交易情况；缺失字段保持未记录，零成交不等于策略有效。辅助读取失败时，重新读取同一结果即可，不需要再次运行。
7. 可以在原行情图表复盘已保存结果。修订参数或采用新数据会建立新的版本，原任务与报告保留。

## 第二天如何继续

重新打开同一程序，先找回原任务和结果。数据更新会区分无变化、新日线、历史修订与来源失败；无变化不新增任务或回测，采用新版本需要明确确认。

“执行演练”内的“逐日模拟”使用支持的原策略完成结果和完整保存日历。先填写模拟名称、初始合成现金、固定整股数量及费用，再核对预览中的起始日期和模型。它从这个历史起始日建立独立模拟，不接续旧报告的末日账户，也不重现原分数股回测收益。当前模型不执行柱内止盈或止损。

先明确记录起始收盘信号，再逐次确认处理界面显示的下一交易日。没有下一完整日线时等待；采用更多已保存数据不会自动推进。暂停、恢复前核对和明确恢复是分别操作，恢复本身不处理下一日。

遇到未知请求时，保留原编号并查询原回执，不另发相同操作。重开后的模拟需核对保存状态再恢复。来源或模型版本不能核验时，只读、暂停和核对仍可用；程序不会自动补算未知结果。

## 订单演练与券商准备

本地订单演练使用独立合成账户。先核对研究版本、资金、风险、方向、数量和价格，预览后再单独确认。接受响应不等于成交；未知结果只核对原请求，不能把本地账本当作独立成交观察。

“券商接入准备”只检查官方模拟或实盘候选资料，并在明确确认后保存未发送意图。它没有连接券商、查询真实账户、解锁或下单。暂停候选准备不等于撤销券商挂单；真实账户与资金另需明确授权和验证。

保存候选资料后，可在“该账户的执行停止”读取共享停止标记。同一模式、同一账户的其他工作区会读取同一标记；离线资料、未发送意图和验收计划仍可准备，另受“停止本模式的意图准备”限制。解除账户停止标记时须核对最近的停止记录并明确确认；它不会解除本模式的准备停止、重新发送旧请求或授予连接和交易权限。当前券商执行尚未启用。响应未确认时，只查询界面保留的原请求回执，不重复点击发送。

## 关闭、重开和旧记录

默认关闭窗口即退出；有任务尚未结束或退出未确认时，程序保留窗口并说明原因。只有明确选择留在托盘才会继续在后台运行。重复打开同一安装和工作区会聚焦已有窗口。

在“工作区与旧结果”核对当前写入位置，也可查找并选择已知旧工作区。旧记录只读，不搬迁、不改写、不重跑；无法校验的记录会明确说明。历史 UNKNOWN 和旧结果保留原身份。
