## 安装与打开

普通安装使用候选 wheel 及精确依赖；Python 3.11 以上，当前工程验证主版本为 3.14。建议给候选一个新目录及独立环境，原包继续保留。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install .\hakimi_research-0.6.0.dev1-py3-none-any.whl
.\.venv\Scripts\hakimi-trade-workbench.exe --workspace .\我的研究 --open-browser
```

工作台只监听本机随机端口，启动时输出实际地址；浏览器和 Electron 使用同一个正式服务。关闭进程后用同一工作区重新打开，即可读取已保存输入、不可变任务版本、结果与连续账本。程序文件与用户数据目录分离。

源码开发仍先安装根目录 `requirements.research.lock` 和 editable 包。Electron 的正式入口由 `npm run start:research` 启动；指定 `HAKIMI_RESEARCH_PYTHON` 为安装了本候选的 Python、`HAKIMI_RESEARCH_WORKSPACE` 为工作区。旧 `npm start` 保留原终端入口。

## 普通使用流程

1. 在数据页选择已有正式快照 JSON，或同时选择价格 CSV 和来源说明 JSON。数据声明沿用 [统一输入合同](input-workflow.md)，必须包含美股正股身份、RTH 日历、完整窗口、未复权价格、股数成交量和公司行为覆盖。
2. 查看可用状态、交易日数量、来源及不能使用的原因。原文和哈希仅证明保存内容身份；导入真实行情仍标注 `IMPORTED_UNVERIFIED`。缺失或公司行为不受支持时不补造数据。
3. 创建双均线任务，选择评分日期、均线窗口、仓位、止损止盈、费用和滑点；参数只是用户研究假设。评分起点必须晚于所需预热。创建买入持有任务作基准时使用相同数据、评分区间、资金与成本。
4. 运行后查看净收益、回撤、费用、成交与逐条原因。基准无策略止损/止盈，主动策略有其自身退出规则；对照页保留这些区别。
5. 关闭重开后选择保存结果。比较只读取通过校验的结果；来源、数据、评分区间或成本不同会说明不可比，不把不同任务独立本金收益加成组合收益。
6. 需逐日续接时，用明确任务集合和共享资金限制新建连续研究账户。详见 [连续运行与恢复](continuous-runtime.md)。

## 内核维护与升级

正式计算修复进入 `src/hakimi_research`，新增普通任务默认使用它。旧终端引擎及封存包保持旧结果读取、原格式回放和必要修复；旧结果的公式、来源与账本不能改签成正式内核输出。三个行情洞察保持在原终端路径，使用时仍展示各自来源和计算合同。

既有任务族沿用不可变版本和显式选择。连续账户绑定建立时的任务配置、源代码与依赖身份；参数变动不自动变更旧仓位规则。升级后历史回执可读，继续写入必须使用匹配的原运行环境；新候选用新账户开展研究，不自动搬移旧合成持仓。来源或依赖不匹配会显示停止原因。

## 研究输入

首版只接财报排期：研究侧 `collaboration_result_v1` 加上与其哈希对应的原始 `equity-event-context-v1`，经人工明确确认后进入原输入检查与任务版本流程。没有原文、时间、完整修订链或确认时保留拒绝原因。接口成功和研究意见不能自动更改策略参数或开启订单。见 [排期适配合同](collaboration-schedule-adapter.md)。

## 本轮边界

本地研究写入只影响所选工作区。正式服务不导入 Provider、账户或交易路由；研究模拟不连接券商。原终端的只读启动与订单锁继续独立保留。Unknown/T3、历史观察任务保持暂缓；P2 数据范围/策略晋级和 P3 受控交易留待后续阶段。
