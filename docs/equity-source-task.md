# 离线股票公告任务

这个入口把“资料清单 → 导入 → 原件核对 → 必要人工复核 → 只读结论”连成一次操作。只改清单和本地资料即可选择支持格式内的证券、财季及版本，不需要修改 Python 源码。它复用现有 AMD 提取与独立审计、精度比较、价格确认规则、行情快照验证和静态卡片；不调用回测执行器。

这是开发分支中的仓库工具，正式 v0.2.1 和原 r3 包尚不包含该入口。AMD 固定十事件规约和旧证据保持不变。NVIDIA 已用三份官方原件完成两个财季的[有限真实格式验收](research-evidence/equity-source-task-20260927/README.md)，不能据此宣称通用解析能力、人工核准或独立策略验证。

## 一次离线操作

在已有研究 Python 环境、仓库根目录运行：

```powershell
python -B tools/equity_source_task.py run --manifest examples/equity-source-task/manifest.synthetic.json
```

此演示的两份小型 HTML 是明确的虚构资料，不是从 NVIDIA 网站取得的原件。成功后命令返回 `packet` 和 `report` 路径，打开 `report` 目录下的 `index.html` 查看卡片。输出默认落在 `artifacts/source-task-demo`，不会替换旧 AMD 报告。

替换为真实资料时，复制清单，填入已获准使用的本地路径、原件 SHA-256、官方链接和实际采集时间，并固定事件列表。SHA-256 可用 `Get-FileHash -Algorithm SHA256 <原件路径>` 取得；它绑定字节，不认证来源真实性。清单中的路径相对清单本身解析，输出目录必须显式提供。导入不会访问这些链接，也不会自动补齐缺失文件。

## 清单要表达什么

| 项目 | 用法 |
|---|---|
| `evidence_kind` | 明确区分虚构夹具与真实留存的当前官方 HTML；演示不会显示成真实来源验收 |
| `security` | 稳定证券标识、名称、货币及有限格式适配器；身份仍为调用者声明 |
| `selection` | 在查看价格结果前固定选样原因、价格规则、停止门槛；本版本成本与收益明确不计算 |
| `source_scope` | 纳入的披露类别和仍未覆盖的渠道；不声称完整历史链 |
| `budget` | 事件数、原件数、单文件及总字节限额；网络与经济运行预算必须为 0 |
| `timing` | 历史重建中的采集／处理延迟假设，与实际采集、提取时间分开 |
| `sources` | 本地原件、字节摘要、公开来源、实际采集时间、合法用途声明、已知版本及覆盖口径 |
| `events` | 财季、披露核查窗口、正式结果、全部已选在先披露、已知重大披露清单 |
| `market_snapshot` | 可选的已有合法本地行情快照；沿用现有导入格式和身份检查，不读取账户或行情接口 |
| `previous_packet` | 来源变化时指向前一份任务包；新包递增版本并记录前身摘要，旧包不改写 |

当前格式适配器：`amd-earnings-html-v1`（AMD 官方新闻格式）和 `nvidia-earnings-html-v1`（受限 NVIDIA GAAP 摘要及百分比指引格式，支持所查的 FY24 两位年份和正文日期）。选择其他发行人或格式会停止该事件，不把 AMD 正则套到任意公司。适配器支持表格分开的美元符号与数值单元格，排除非 GAAP 和全年表，并独立核对数值。

`coverage` 不是自动认证的并表结论：必须按原文及用途声明，缺失为 `UNKNOWN_COVERAGE`，不同则为 `NOT_COMPARABLE`。不同财季、未支持单位、歧义字段、已知初步披露未纳入或缺原件也有明确停止状态。有限扫描未发现另一次披露不等于全球不存在披露。

## 原件、审核与报告版本

任务目录包含保留的原始字节、私有输入清单和 `packet.json`。每项提取能定位来源摘要、规范文本偏移和引文；比较引用具体在先版本。只有日期的页面不会被补成一个虚假的公开时刻，模型可用时间及价格信号保持未具备。当前网页历史不变性始终未证明。

```powershell
python -B tools/equity_source_task.py verify --packet <任务目录>/packet.json
python -B tools/equity_source_task.py report --packet <任务目录>/packet.json
```

原件或提取结果变化不能在旧身份下通过核验。相同报告重复生成只核对已有内容；输入变化创建新任务版本，不覆盖旧报告。提取代码变化时，需要新任务身份；卡片代码变化产生新的报告身份。

若后续有明确用途且人已审核具体字段，可以单独导入人工声明文件：

```powershell
python -B tools/equity_source_task.py report --packet <任务目录>/packet.json --approval <人工声明.json>
```

声明必须绑定当前 `packet_hash`，使用 `source-task-human-review-v1`、`reviewer_kind=HUMAN_ATTESTATION`、`decision=APPROVE_SOURCE_FIELDS_ONLY`，列明 `approved_event_ids`、`reviewer`、`source_user_confirmation`、`reviewed_at`。没有真实确认时不要生成批准声明。本工具验证声明的范围与身份绑定，不认证声明者身份；它不会自行批准、回填旧回执或由字段核准推导研究／交易权限。

## 可选行情与停止决定

若提供现有快照，先验证证券身份及日历覆盖，再复用原固定 C 价格确认条件；不更改阈值、窗口或止损。缺少公告前价格基准、精确公告时间或后续完整交易日时，价格信号保持 `null`，不记成不成立。时间假设不符合原 120 秒规则也不会默改。

每份结果分别列事件数、资料可比数、人工核准事件数、行情可用数、价格信号数、数值与价格交集，以及内容干预数。没有行情输入时，行情可用为 0、价格信号与交集为未计算；没有策略执行时内容干预始终为 `null`。多成本情景和重复报告不增加事件数。

本入口的决定始终止于来源流程工程验收，收益研究次数为 0。机会门槛只作预先声明的筛选描述，即使达到也不会开启回测或账户权限。需要后续经济研究时另行固定新资料、成本与批准；新公司也不自动成为未见验证集。

退出码：0 为来源流程检查完成，2 为已保留报告但存在事件资料缺口，1 为清单／身份／文件或操作错误。看到资料缺口应检查该事件的原因，不自动扩大采集范围。联网采集、正式发布、预览更新及监控部署分别处理；T3、Unknown、客服邮件和账户操作仍暂停。
