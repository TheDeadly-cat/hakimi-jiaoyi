# 指标计算口径与历史兼容

当前新增计算使用 `hakimi-indicators-v1`。Python 的 `services/indicator_math.py`
是终端原生信号与研究卡片的共用定义，图表 `static/indicator_math.js` 通过跨语言测试对齐。

| 指标 | 定义 |
| --- | --- |
| SMA | 完整 N 个有效观察值的算术平均；不足 N 个返回缺值 |
| EMA | alpha = 2/(N+1)，首个有效值作种子；缺值后重新起算 |
| BOLL | SMA 加减 K 倍总体标准差，ddof = 0 |
| MACD | 快 EMA 减慢 EMA；信号线为该差值的 EMA；柱值不乘 2 |
| RSI | N 个价格变化的简单平均涨跌幅；平盘 50，只涨 100，只跌 0 |
| ATR | N 个真实波幅的简单平均；每个波幅需要上一收盘价，非 Wilder 平滑 |
| Momentum | N 期连续有效数据的收盘比值减 1 |

缺值、非有限输入与派生溢出不填充为零，不画连续连线。图表先在完整已加载前缀计算，
再裁切视窗；平移、缩放与逐根回放不能改变同一截止时点的数值。实时未完成 K 线可
作为当前图表观察，冻结研究输入仍只接受明确已完成的 K 线。

股票研究卡片不足 50/200 根时不能把较短窗口的值标成 MA50/MA200。需要的窗口不足
时明确显示样本不足；不足 50 根不输出依赖 MA50 的阶段判断。

终端新信号引擎为 `causal-long-only-signals-v7`。新任务、冻结配置和源码身份包含
指标契约及公式源文件；通用回测指纹也包含指标适配器与公式源文件。旧 v6 任务和
报告仍可读取、查看与修订，重新运行需要保存新任务版本。旧记录不改写、不重签。

`vendor/research/hakimi_terminal_research` 是隔离的桌面研究引擎。前置移植仅替换包名引用，
保留原始来源摘要并记录派生源码身份；正式 `src/hakimi_research` 与 CLI 规则不改写：
其 BOLL 为样本标准差 ddof=1；不能把它与当前终端同名策略当作同一算法。
跨引擎和跨公式版本的经济结果仍需保持不可比判定。SMA/EMA/MACD 等相同数值定义
不代表策略触发规则、执行模型或回测结果相同。

验证包括独立算术样例、pandas 参考计算、Python/JS 数值一致、每根前缀不变、
图表视窗预热、缺值断线、仅公式依赖变化即改变指纹，以及旧记录字节不变的迁移测试。

## 判断与复盘记录

在研究工作台选择冻结行情、任务或已完成结果，记录方向、观点、触发条件、失效条件和反证。
`as_of` 是使用数据的截止日，`recorded_at` 是实际写入时间；历史补记不视为当时已经作出的判断。
指标只用截止日以内的冻结前缀计算一次，封存参数、公式、源码身份、前缀行数和哈希。
重新打开仅校验这些保存值与原来源，不用当前算法替换。后续观察、触发、失效和用户报告动作
沿哈希链追加；用户报告动作不等于系统订单或经核验成交。来源或收据缺失显示 UNKNOWN。

## 结构观察与同入场出场研究

冻结行情可独立查看结构。当前默认左右各 3 根，窗口内必须是唯一极值，同价不强行认定转折。
分别保存发生日与确认日；相邻已确认高点比较为 HH/LH，低点为 HL/LL，相等单独标记。
回放滑块未走到确认日时不显示该转折，也不提前显示后续退出。结构查看是当前版本派生观察，
与保存后的不可变出场研究结果有不同身份。

出场研究从原生已完成结果提取同一批 BUY 入场，保留信号日、入场日、价格、数量和原费用。
第一版不接受 ADD。先登记训练、验证、测试三段六个日期边界与规则，再明确运行一次。
原结果由其原策略及原出场规则选出入场样本，仍有选择偏差；这不是未见样本的预测证明。

- 固定比例止损。
- ATR 移动止损：以入场价和后续已完成收盘价的最高水位为基准，使用上一完成 K 线的简单 ATR；不是 Wilder 平滑。
- 已确认结构止损：入场前必须已有低于入场价的确认支撑，随后只向上更新。

三种规则共用紧急保护、观察期限、出场费率与滑点；原入场费用保持原样。除入场开盘设定初始
保护外，下一根阈值由上一根完成数据决定。不能先用当前最高价抬止损，再用同根最低价触发。
跳空按开盘价，盘中触及时按阈值，之后统一扣滑点和费用；只有日线，退出当天的后续最高最低
先后无法确定，MAE/MFE 不计未知的退出后极值。

达到分段边界或最长观察期仍未触发，记 CENSORED，不虚构已实现收益；入场依据不足记
UNAVAILABLE。只在两条规则均退出的同一入场上统计配对差值，并列出排除样本数。
已退出样本的均值、最差值、费用与时长不能代表被排除样本的表现。
各样本独立且可能重叠，不合成账户权益曲线，不授予模拟或实盘权限。

所有新增记录位于独立的 terminal-judgments、terminal-exit-experiments、terminal-exit-runs
及相应请求收据目录。原任务、报告、vendor 内核及原有行情/模拟记录/数据记录入口保留。
新计算前校验已加载源码与磁盘一致；不一致需要重新加载后台，历史结果读取不重算。

## 行情洞察：多周期结构、同行业强弱与指标说明

从原图表的行情洞察入口或研究工作台进入。选择已封存日线和观察日期；需要补充标的时，
沿用原“读取本地日线 → 核对来源 → 保存行情快照”流程。洞察 GET 仅做只读派生计算，
不运行策略、不改写封存输入、历史判断或实验报告，也不修改原图表的周期和视窗。

多周期首版支持日、周、月。股票仅用常规时段，按 XNYS/XHKG 日历核对完成交易日；加密日线
按 UTC 全天日历。未知日历、缺失交易日、尚未收盘或未到声明可用时间的数据不生成结构或
当前指标值。周/月首段不完整及尾段尚未结束的周期被排除；假期缩短周按最后应有交易日完成。
每个周期继续使用左右各 3 根的唯一枢轴定义，分别显示发生日和确认日。各周期到支撑/阻力
的距离统一使用观察日最后完成日线的收盘价；周期自身最后完成日期和收盘价另列，不混用。

同行业界面可按项目配置分组或自行选择 2 至 8 个股票封存输入，首个选项作为比较基准。
要求同市场、币种、来源、时段与价格口径，比较区间必须逐交易日齐备，不用静默求交集或
前向填充掩盖缺失。显示收盘价变化、归一化曲线、相对基准百分点差和收益相关性；相关性
至少需要 20 个收益样本。不额外计入分红或成本，价格本身已包含的调整以显示的价格口径为准。
`config.STOCK_MARKETS` 的 sector 是项目配置分组，缺少权威分类及历史生效证据，始终明确
`historical_membership_verified=false`，不能将自选或静态配置提升为历史时点同业证明。

指标卡调用既有 `indicator_math.py`，显示所选冻结前缀的实际数值、固定观察参数、最低样本数、
公式版本和误用边界；卡片参数不是当前策略任务的参数。SMA/EMA/BOLL/MACD/RSI/ATR/Momentum
口径见本文首表。尤其 RSI 与 ATR 使用简单滚动平均，不等于 TradingView 默认 Wilder/RMA。
外部官方资料是概念对照，不提供第三方受保护源码或收益证明。

洞察结果使用独立 schema、派生结果哈希、前缀数据哈希、交易日历哈希和相关源码哈希。
历史观察是对选定封存快照的截断，不证明该供应商在历史当时未修订数据，也不提供历史行业
成员证明。后续源文件变化需要重新加载后台，原不可变研究报告保持原身份。
