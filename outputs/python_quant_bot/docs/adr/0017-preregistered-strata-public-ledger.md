# ADR 0017: Preregistered strata public ledger

## Status

Accepted as a redacted consumer and standalone frontend component. It is not
mounted in the main application and does not activate a writer or current
pointer.

## Decision

Add strategy-correlation-preregistered-strata-public-summary-v1. The projection
independently verifies the source registration and, when supplied, the strata
gate and complete-link gate. Invalid, partial, re-sealed, or authority-escalated
inputs project to UNKNOWN.

The public payload exposes only cluster, stratum, dimension, and blocked-
dimension counts plus fixed policy values. It does not expose symbol, cluster,
or stratum identities; artifact hashes; correlations; returns; or rankings.

Add a vote-compression independence ledger that renders the existing neutral
sequence SOURCE to GAP to MATURITY to PERMISSION. Its visual signature shows
anonymous cluster marks converging into fewer preregistered stratum bands before
the evidence sequence. The component uses a cool mineral, oxide, and tidal
palette with condensed instrument typography, responsive stacking, visible
focus, and reduced-motion handling.

## Boundary

The summary is descriptive research governance. Consumer-only maturity and
research-only permission are explicit. Current admission, writer activation,
paper authorization, and live ordering remain false. No result is profitability
evidence or trading authority.

## Activation order

1. Keep the projection and ledger standalone under frontend suite-v3.
2. Freeze and fingerprint a formal hierarchy registry asset.
3. Define report-schema integration and a formal writer.
4. Mount the ledger in the main application only after its data route is
   versioned and independently reviewed.
5. Treat any current migration as a separate decision.
