# 哈基米交易 v2 行情研究工作台方案

## 产品定位

哈基米交易 v2 的主方向从“交易执行平台”调整为“行情分析与市场异动捕捉软件”。软件优先帮助用户发现异动、理解走势、识别多空力量变化，并把结论沉淀为可追踪证据链。模拟盘和策略研究继续保留，实盘真实下单继续保持硬保护墙。

## 可复用模块

- `market_scanner`：复用现有多标的扫描、涨跌幅、振幅、区间位置、成交额排名，升级为异动雷达的数据底座。
- `research_panel`：继续作为研究工作台入口，承载新闻、事件、热点排行、雷达和走势驾驶舱。
- `local_market_ai_analysis`：复用K线、成交量、画线、支撑压力、止盈止损和多空胜率估计。
- `market_dual_ai_analysis`：继续执行 DeepSeek 第一遍分析、GPT 第二遍复核，两份输出都展示给用户。
- `contract_center` 和 `market_insights`：复用资金费率、未平仓量、标记价、指数价、基差、盘口和合约异常。
- `full_configuration_snapshot`：继续作为全局配置总控，保持 AI、数据源、模拟盘、风控和实盘硬锁的状态汇总。

## 新模块

### 行情异动雷达

雷达列表字段：时间、标的、市场类型、方向、评分、严重度、异动原因、类型标签、价格、涨跌幅、振幅、区间位置、成交量排名、证据、风险说明。

评分因子：急涨急跌、放量、接近突破或跌破、波动率扩张、资金费率异常、合约基差异常、股票/币种同步异动。

输出边界：只标注“观察 / 仅研究 / 仅模拟盘验证”，不生成实盘下单指令。

### 走势分析驾驶舱

卡片字段：趋势状态、波动、量能、多空概率、关键价位、安全边界。

核心解释：判断震荡、突破、回调、反转、假突破风险；给出关键支撑压力、成交量确认、反证和等待条件。

### 异动解释 AI Prompt

AI 输入使用结构化行情数据：雷达异动、K线快照、成交量、资金费率、OI、基差、盘口、支撑压力、新闻事件和安全边界。

AI 输出必须是 JSON，并包含：summary、anomaly_type、severity、direction_bias、long_win_rate_pct、short_win_rate_pct、止盈区、止损区、evidence、counter_evidence、waiting_conditions、risk_notes、safe_action。

## 安全边界

- 不保存真实 API 密钥。
- 不打开实盘交易。
- 不允许 AI 绕过风控。
- 胜率只能表述为当前样本和规则估计，不能写成保证性结论。
- 所有结论必须显示“观察 / 仅研究 / 仅模拟盘验证”。
