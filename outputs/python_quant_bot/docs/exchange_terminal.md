# 哈基米交易 v2 Exchange Terminal

这是量化机器人项目的交易所级前台终端。它的目标不是人工炒币软件，而是把行情、历史数据、策略执行和风险信息放在一个接近真实交易所的工作界面里。

## 启动

双击：

```text
start_exchange_terminal.bat
```

默认地址：

```text
http://127.0.0.1:8765
```

这个终端使用 Python 标准库后端，不依赖 Streamlit、pandas、numpy 或 ccxt。

## 当前已铺设功能

- 市场列表：BTC、ETH、SOL、OKB、XRP、DOGE
- 市场分类：全部、主流、Layer1、Meme
- 全市场实时价格面板：后台 WebSocket 更新所有自选币最新价、涨跌、成交额、买卖价
- 软件式导航：交易台、策略、订单、账户、数据、系统
- 快捷键：1/2/3/4/5/6 切换模块，T 切换主题
- 实时价格：OKX WebSocket `tickers` + 本地后端 1.5 秒 ticker 兜底轮询
- 实时盘口：OKX WebSocket `books5`
- 实时成交：OKX WebSocket `trades`
- K线主图：OKX K线接口 + Canvas 绘图，支持悬停查看开高低收、拖动查看历史、滚轮缩放
- 实时当前K线：ticker 跳动会同步更新当前交易中的K线高低收
- 画线工具：支持趋势线、水平线、斐波那契回撤线，斐波包含 0 / 23.6 / 38.2 / 50 / 61.8 / 78.6 / 100
- AI图形分析：结合当前视窗趋势、波动区间和最近一组斐波线，提示关键支撑/压力和策略倾向
- 本地历史：读取 `Z:\jiaoyiguowangshuju\btc_daily_prices.csv`
- 策略执行台：双均线、网格、布林带、MACD、RSI、动量、马丁格尔、反马丁、利弗莫尔突破、海龟交易、达瓦斯箱体
- AI风控建议：根据本地历史库估算止盈、止损、盈亏比和盈利概率，允许手动固定价或百分比覆盖
- 移动风控：支持移动止盈、移动止损、只减仓模式
- 委托设置：支持市价、现价、限价模拟委托
- 保证金模式：支持全仓、逐仓模拟展示和强平估算口径
- 模拟盘账户：现金、持仓、权益、已实现/未实现盈亏
- 模拟盘持久化：状态保存到 `runtime/exchange_terminal_state.json`
- 账户中心：资金账户、交易账户、理财账户
- 资产划转：本地账本划转记录
- 模拟订单流：策略触发后的虚拟订单
- 交易流水：事件写入 `runtime/exchange_terminal_ledger.jsonl`
- 终端配置：账户中心、通知、指标配置保存到 `runtime/exchange_terminal_profile.json`
- 系统设置：主题、界面密度、刷新频率、启动模块
- 主题切换：深色交易台、午夜蓝、高对比
- 布局预设：经典交易、行情专注、策略分析
- 终端事件：读取 `runtime/exchange_terminal_ledger.jsonl`
- 数据导出：订单 CSV、事件 CSV，保存到 `runtime/exports`
- 策略市场：安装/移除本地策略模板
- 通知中心：策略、划转、配置事件提醒
- 策略守护：本地心跳、巡检次数、运行状态
- 后台守护入口：预留独立后台进程启动位
- K线指标：MA、BOLL、VOL、信号点叠加
- 条件委托：模拟触发价、方向、仓位比例、撤销
- 订单筛选：全部、买入、卖出
- 策略信号流：ARM、HOLD、BUY、SELL、EXIT 等状态
- 策略详情：说明、适用风格、核心参数、最近信号
- 订单历史：模拟盘订单的历史视角
- 策略排行榜：基于本地 BTC 日线库做行情适配评分
- 风险中心：回撤、现金、保证金占用、预估强平价、熔断观察状态、AI止盈、AI止损、盈利概率估算
- 权益曲线：本地模拟盘权益变动
- 合约信息：资金费率、资金费率历史、未平仓量、合约乘数
- API 接入面板：展示当前授权状态，保存环境变量名称映射，预留实盘入口
- 往期价格表：展示 BTC 日线数据库

## 安全边界

当前终端里的订单、条件委托和策略执行都是本地模拟盘，不会向 OKX 发送真实下单请求。API 面板只保存环境变量名称映射，不保存真实密钥。真实交易必须等 API Key 管理、二次授权、风控熔断和模拟盘记录持久化完成后再打开。
