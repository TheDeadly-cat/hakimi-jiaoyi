# OKX Quant Desk 本地软件雏形

这是一个无需安装额外依赖的本地网页软件原型。

## 当前已完成

- 产品主线调整为：交易台、策略广场、策略对比、自动模拟
- 旧管理项已归档到交易历史：账户、回测、模拟盘、风控、复盘
- 本地后台服务
- 可操作网页界面
- 左侧类别独立浏览
- 总览页显示全部核心区域
- OKX 公开真实行情接入
- 现货、永续合约、交割合约 ticker 展示
- 市场数据页 5 秒自动刷新
- OKX 合约与币种基础信息展示
- OKX 历史 K 线导入，保存到本地 `data/history`
- BTC 实时价格持续刷新
- OKX WebSocket 实时交易台
- 盘口、成交流、实时价格曲线
- 交易所式模拟下单面板
- 左侧市场列表、中间盘面、右侧盘口和下单区、底部持仓/策略日志
- 分时图 / K线图 / 深度图切换
- 1m / 5m / 15m / 1H / 4H 周期切换
- 指数价、标记价、资金费率、持仓量展示
- 杠杆倍数、全仓/逐仓、限价/市价/计划委托、止盈止损输入
- 策略广场：集中查看不同策略产品
- 策略对比：同一交易对下比较多策略表现并一键采用
- 多品种自动交易模拟引擎
- 每个品种独立交易锚点
- 交易侧盘面资讯聚合
- 模拟行情
- 均线策略配置
- 策略模板库：均线、网格、定投、马丁、反马丁、利弗莫尔、RSI
- 历史回测
- 模拟盘启动和推进
- 风控暂停和恢复
- 交易复盘文本

## 安全状态

当前版本默认锁定实盘，只做模拟交易，不会真实下单，也不会动用 OKX 真实资金。

OKX 行情接口使用公开数据，不需要 API Key。账户私有数据和真实交易仍未开放。

自动交易模块当前是 dry-run 模式：会根据策略和锚点生成模拟决策日志，但不会向 OKX 提交订单。

实时交易台会优先尝试连接 OKX 公共 WebSocket。若网络不可用，会自动使用本地每秒刷新兜底数据。

## 占用空间和内存

当前项目文件很小，不到 1MB。运行时主要占用浏览器内存和一个本地 Node 服务内存，通常是几十 MB 级别，和 8T 硬盘容量没有直接关系。

## 启动方式

推荐方式：

双击 `OPEN_OKX_QUANT_DESK.bat`，它会启动本地服务并打开浏览器。

如果浏览器提示无法访问，通常表示本地服务窗口没有启动成功，或被你关闭了。请看最小化的 `OKX Quant Desk Server` 窗口，它会显示真实访问地址。

备用方式：

双击 `START_OKX_QUANT_DESK.bat`，然后打开终端里显示的本地地址。

默认地址通常是：

```text
http://127.0.0.1:4173
```

如果端口被占用，服务会自动尝试下一个端口。

## 停止方式

如果使用 `START_OKX_QUANT_DESK.bat`，关闭打开的终端窗口即可停止。

如果使用 `OPEN_OKX_QUANT_DESK.bat`，会有一个最小化的服务窗口，关闭它即可停止。
